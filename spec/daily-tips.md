# Daily Tips

Two starter libraries of 120 tips each, one for Tops and one for bottoms: one tip a day for about four months before any repeat. Every tip is original, written in Ember's voice and informed by the sources reviewed. In discreet mode, the notification reads only "Your daily note is ready" and the tip shows inside the app.
